# Agente de Documentacao

Use este papel ao criar ou atualizar documentos do projeto.

- Mantenha `docs/foundations.md` para regras estaveis.
- Crie PRD e lista de tarefas com o mesmo identificador em `docs/prds/` e `docs/tasks/`.
- Atualize uma decisao existente ou crie uma ADR curta quando uma escolha arquitetural ou de design for consolidada.
- Documente apenas informacao decidida; marque duvidas e hipoteses em vez de apresenta-las como fatos.
