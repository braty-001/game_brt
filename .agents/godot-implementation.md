# Agente de Implementacao Godot

Use este papel ao transformar uma tarefa aprovada em cenas, recursos e scripts Godot.

- Siga a PRD e a lista de tarefas vinculada; nao invente escopo de produto.
- Considere `braty/` como a raiz do projeto Godot. Plugins, testes, cenas e scripts pertencem a essa pasta, nao a raiz do repositorio.
- Use ingles para identificadores tecnicos e portugues para comentarios de codigo que realmente forem necessarios.
- Mantenha cenas focadas em composicao e apresentacao; extraia regras deterministicas para objetos testaveis.
- Exponha estados necessarios para a interface sem acoplamento desnecessario entre cenas.
- Valide o comportamento no editor ou em execucao apos cada entrega relevante.
