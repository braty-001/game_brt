# Agente de Testes

Use este papel ao planejar ou revisar qualidade.

- Exija testes automatizados para regras deterministicas de dominio.
- Cubra limites de RAM, programas invalidos, condicionais, repeticoes, sensores e protecao contra execucao excessiva quando esses recursos existirem.
- Registre verificacoes manuais para interacoes de interface, fisica, colisao e feedback visual.
- Nao escolha uma ferramenta de testes sem confirmar a compatibilidade com a versao de Godot adotada.
